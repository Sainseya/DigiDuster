## About The Project

Play as a heroic mouse cursor in **DigiDuster**, a captivating roguelike where you explore a virtual Windows desktop, destroy hidden viruses, upgrade your abilities through desktop icons, and track down the source of an imminent digital threat to save the system.

### Features

- **Computer Immersion**: Travel through folders inside a virtual computer to find and eliminate viruses.
- **Item Combinations**: Collect items from desktop icons to build your own strategy against your enemies.
- **Boss Fights**: Find and destroy the boss of each level, each representing a well-known computer threat.
- **Random Generation**: Every playthrough is different thanks to randomly generated levels and areas to explore.

## Getting Started

To play DigiDuster, follow these steps.

### Prerequisites

- **Java**: download the latest version from [oracle.com](https://www.oracle.com/java/technologies/downloads)
- **Gradle**: download from [gradle.org](https://gradle.org/install)

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/EpitechMscProPromo2026/T-JAV-501-LIL_16.git
   ```

2. **Configure Gradle:**

   From the project directory, run:

   ```sh
   gradle init
   ```

   This generates the necessary Gradle configuration files. Follow the prompts to configure Gradle for your needs.

3. **Run the application:**

   From the project root:

   ```sh
   gradle run
   ```

   This compiles and launches the LibGDX application.

## Usage

1. **Main Menu**

   - Launch the game to reach the main menu.
   - Adjust the game's sound volume from here.
   - Click "Play" when you're ready.

2. **Player Controls**

   - Move with the **ZQSD** keys.
   - Attack with the **Space bar**.
   - Enter a folder with **Enter** while your cursor is over it.
   - Exit a folder with **Escape**.

3. **Fighting Viruses**

   - Entering a folder may trigger a fight against viruses.
   - You cannot leave the folder while viruses are alive.
   - Defeating viruses with your projectiles rewards you with a bonus item.

4. **Boss Fights**

   - Some folders contain a boss to destroy.
   - Defeating the boss grants you an item and unlocks the next level.
